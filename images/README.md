# Screenshot Policy

All screenshots in this repository are sanitised project evidence.

Before uploading an image:

- Blur IP addresses, MAC addresses, hostnames, usernames, passwords, API keys, QR codes, cloud URLs, and tokens.
- Do not publish RTSP URLs or MQTT payloads containing private information.
- Do not publish Home Assistant secrets, SSH keys, Docker `.env` files, PostgreSQL credentials, or CompreFace API keys.
- Blur visitors, neighbours, unknown persons, licence plates, addresses, and identifying home details.
- Only show known enrolled faces if written consent has been obtained.
- Prefer cropped screenshots, diagrams, entity pages, traces, and configuration examples.
- Never upload raw snapshots, recordings, face libraries, training images, database exports, or backups.
